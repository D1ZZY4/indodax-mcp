<h1 align="center">Market tools</h1>

Public, read-only, no credentials. Every pair argument accepts any common
spelling (`btc_idr`, `BTCIDR`, `BTC/IDR`); the server normalizes it into the
exchange wire spelling per endpoint.

| Tool | Parameters | Response `data` | Notes |
| --- | --- | --- | --- |
| `indodax_server_time` | none | `{ timezone, server_time }` (ms) | Clock sync. |
| `indodax_pairs` | none | Array of `{ id, symbol, base_currency, traded_currency, ticker_id, trade_min_*, price_precision, quantity_increment, trade_fee_*, is_maintenance?, is_market_suspended?, tradable }` | `ticker_id` like `btc_idr` is the canonical input spelling. `tradable` is false for suspended or maintenance markets; skip those before spending orderbook calls on them. |
| `indodax_ticker` | `pair` string required | `{ high, low, last, buy, sell, server_time?, symbol, fetchedAt, rangePct, pos, spreadPct }`, money as strings | Cached 30s. Same derived screening fields as bulk rows. Depth in quote currency still needs `indodax_orderbook` or `indodax_quote`. |
| `indodax_tickers_all` | `quote`? 1-10, `limit`? 1-500 (default 100 only when neither quote nor limit is given; limit caps returned rows, total is the universe size), `fields`? array, `minVolumeIdr`?, `minRangePct`?, `maxSpreadPct`?, `minPos`?/`maxPos`? 0-1 | `{ count, matched, total, quote, limit, fields, tickers, pairs, summary }` | Screening-ready by default: rows carry `last`, `high`, `low`, `buy`, `sell`, `vol_idr` plus derived `rangePct` (24h range pct of low), `pos` (last position in high/low), and `spreadPct` (pct of bid) whenever computable. All bounds combine with AND; a row that cannot produce a needed value fails the bound. `matched` counts rows passing filters before the limit cap, `count` counts returned rows. |
| `indodax_search_symbols` | `query` required free text, optional `quote` filter, `limit` 1-200 default 25 | `{ query, matched, tradable, returned, pairs, suspended, note, summary }` | Resolve an unverified ticker against the live pair list before calling anything else. Returns `pair`, `quantityIncrement`, `tradeMinQuote`, and `suspended` per row. Unknown names come back as `matched: 0` with a note, not an error, so a screener never has to guess. |
| `indodax_orderbook` | `pair` required, `levels` int 1-100 default 20 | `{ buy, sell, bestBid, bestAsk, bestBidQty, bestAskQty, spread, spreadPct, mid, empty, note }`, money as strings | `bestBid`/`bestAsk` use the same names as `indodax_quote`. `null` on an empty side, never `0`; `empty: true` marks a one-sided book. `spreadPct` is a percentage of mid. A market without a quotable book fails with `PAIR_UNAVAILABLE` naming the pair and pointing at `indodax_search_symbols`, not a raw shape error. |
| `indodax_trades` | `pair` required, `limit` int 1-500 optional (default all) | `{ pair, count, total, limit, trades, flow: { buyCount, sellCount, buyRatio }, flowWarning?, summary }` | `type` is lowercase `buy`/`sell`. `flowWarning` reports `seller-dominated` below 0.2 or `buyer-dominated` above 0.8 buys on samples of 10 or more trades. |
| `indodax_candles` | `symbol` required (any spelling), `timeframe` default `"60"` (`1, 15, 30, 60, 240, 1D, 3D, 1W`), `from`/`to` unix seconds default last 24h | Array of `{ Time, Open, High, Low, Close, Volume }`; money fields are strings, `Time` is unix seconds | Symbol is uppercased to compact form (`BTCIDR`) before the call. |
| `indodax_price_increments` | none | Raw exchange payload | Shape-level only. |
| `indodax_summaries` | none | `{ tickers, prices_24h?, prices_7d? }` | 24h/7d overview. |
| `indodax_quote` | `pair`, `side` BUY/SELL, `quantity` positive base units, `price`? limit | `{ pair, side, quantity, requestedPrice, bestBid, bestAsk, estimatedAvgPrice, fillableQuantity, verdict, note }`, money as strings | Read-only pre-order estimate, never places anything. `verdict` is `instant` (fills around the estimate), `parked` (limit misses the book), or `partial` (depth covers only `fillableQuantity`). |
| `indodax_round_order` | `pair` required, `side`? context only, `quantity` positive base units, `price`? | `{ pair, quantity, price, adjusted, original, rules, notional, notes, summary, remedy }`, money as strings | Read-only preflight against the live pair list: quantity rounds down to the pair increment and price down to its precision. Reports the real numbers for a rule that blocks the order, such as an increment that leaves nothing tradable or a notional under the pair minimum. `indodax_search_symbols` reports the same `rules` per row so an order can be sized before it is placed. Offline, the pair list is unreachable and the call explains that instead of guessing a rule. |

Errors: `ValidationError` for bad pairs, `ExchangeApiError`/`ExchangeNetworkError` for upstream failures (retryable only for network/rate-limit codes).

Related: `indodax_ws_ticker` (one-shot WebSocket snapshot), `market://snapshot` and `pairs://metadata` resources.
