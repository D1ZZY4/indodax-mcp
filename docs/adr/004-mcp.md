# ADR-004: MCP tool surface

- Status: historical decision carried into the TypeScript rebuild.
- Current location: packages/mcp-* and packages/indodax-mcp.

## Decision

Serve stdio and HTTP through one registry and one application composition. Keep transport concerns separate from tool definitions and application services.

The current surface is grouped around market, account, orders, portfolio, risk, paper, strategy, backtest, alerts, reconciliation, audit, system, funding, history, and operations.

## Safety consequence

Paper is the supported mutation mode. The current application policy denies live execution, and withdrawal has no server-side grant path.

Tool metadata defines the expected capability, environment, authentication, destructiveness, idempotency, and audit class. The generic mcp-core dispatcher does not centrally enforce every field, so sensitive guards remain executable in handlers and services.
