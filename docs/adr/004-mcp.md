# ADR-004: MCP tool surface

> Historical record from the Rust workspace. Current groups are
> market, account, orders, portfolio, risk, paper, strategy, backtest,
> alerts, reconcile, audit, system, funding, history, and ops.

* Status: accepted.
* Decision: one shared registry and dispatch serves stdio and HTTP.
  Tools are grouped by capability (market, account, orders,
  portfolio, risk, paper, strategy, backtest, alerts, reconcile,
  audit, system, funding, history, ops). Mutations run paper by
  default; live needs policy, capability, credentials, and explicit
  acknowledgement. Withdrawal stays denied without a separate grant.
* Consequence: transports cannot diverge in behavior, and no tool can
  bypass risk or reach the exchange client directly.
